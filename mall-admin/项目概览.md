# 商城管理后台系统 - 项目概览

## 项目信息

- **项目名称**：商城管理后台系统 (mall-admin)
- **架构模式**：全栈一体化
- **开发完成度**：100%
- **创建时间**：2025-11-01

## 技术栈

### 后端
- **框架**：Node.js + Express
- **数据库**：MySQL (使用mysql2连接池)
- **认证**：JWT (jsonwebtoken)
- **密码加密**：bcrypt
- **文件上传**：Multer
- **其他**：cors, dotenv, express-validator

### 前端
- **框架**：Vue.js 2.6
- **UI组件库**：Element UI
- **路由管理**：Vue Router
- **状态管理**：Vuex
- **HTTP请求**：Axios
- **图表库**：ECharts
- **其他**：js-cookie

## 核心功能特性

### ⭐ 左侧树型菜单栏
- 采用Element UI的Menu组件实现
- 树型结构清晰展示功能模块
- 支持一键折叠/展开
- 当前路由自动高亮
- 子菜单自动管理

### 📊 数据统计仪表盘
- 4个核心指标卡片（订单、销售额、用户、商品）
- 今日数据统计（新增用户、订单数、销售额）
- 本月数据统计
- 待处理事项提醒
- 近7天销售趋势图表（ECharts）

### 🛍️ 商品管理
- 商品列表（分页、搜索、筛选）
- 商品新增/编辑
- 单图上传（主图）
- 多图上传（轮播图，最多5张）
- 上下架管理
- 推荐设置
- 排序管理

### 📂 分类管理
- 分类列表（分页、搜索）
- 弹窗式新增/编辑
- 分类图片上传
- 关联商品数量显示
- 删除前检查关联商品

### 🎠 轮播图管理
- 轮播图列表（分页、搜索）
- 弹窗式新增/编辑
- 轮播图上传（建议尺寸750x300）
- 跳转链接设置（商品详情/外部链接）
- 上下架管理
- 排序管理

### 📦 订单管理
- 订单列表（分页、搜索、状态筛选、时间范围筛选）
- 订单详情查看
- 订单发货（仅待发货状态可操作）
- 订单关闭（仅待支付/待发货可操作）
- 订单状态标签展示

### 👥 用户管理
- 用户列表（分页、搜索、状态筛选）
- 用户详情查看
- 用户头像展示
- 统计信息（订单数、地址数）
- 启用/禁用用户

### 🔐 权限管理
- 管理员登录
- JWT Token认证
- 自动token续期
- 修改密码
- 安全退出

### 📤 文件上传
- 支持jpg、png、gif、webp格式
- 文件大小限制（5MB）
- 实时预览
- 上传进度提示

## 特色亮点

1. **左侧树型菜单**：采用Element UI的Menu组件，实现树型结构展示，支持折叠/展开
2. **全栈一体化**：前后端在同一项目中，部署简单，开发高效
3. **完整的CRUD**：每个模块都实现了完整的增删改查功能
4. **用户体验优化**：加载动画、操作确认、实时反馈
5. **安全认证**：JWT Token、中间件拦截、自动登录态管理
6. **响应式设计**：适配不同屏幕尺寸
7. **错误处理**：完善的错误处理和日志记录
8. **代码规范**：统一的代码风格和命名规范

## 使用的设计模式

1. **MVC模式**：后端采用Model-View-Controller架构
2. **中间件模式**：Express中间件处理认证、验证、错误
3. **工厂模式**：统一的响应格式封装
4. **单例模式**：数据库连接池、Vuex状态管理
