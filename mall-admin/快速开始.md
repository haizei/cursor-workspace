# 快速开始指南

## 3分钟快速启动

### 第一步：准备数据库

```bash
# 1. 登录MySQL
mysql -u root -p

# 2. 创建数据库并导入表结构
CREATE DATABASE mall DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE mall;

# 3. 执行项目需求文档中的建表SQL（在 商城小程序项目需求/数据库建表语句.sql）
source /path/to/数据库建表语句.sql;

# 或者直接复制SQL内容到MySQL客户端执行
```

### 第二步：配置环境变量

编辑 `.env` 文件：

```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的MySQL密码
DB_NAME=mall
```

### 第三步：安装依赖

```bash
# 安装所有依赖（前端+后端）
npm run install:all
```

### 第四步：启动项目

**开发模式（推荐）**

```bash
# 终端1 - 启动后端
npm run dev

# 终端2 - 启动前端
npm run frontend:dev
```

然后访问: http://localhost:8080

**生产模式**

```bash
# 构建前端
npm run frontend:build

# 启动服务
npm start
```

然后访问: http://localhost:3000

### 第五步：登录系统

- 访问登录页面
- 用户名: `admin`
- 密码: `admin`

## 注意事项

1. **数据库必须先创建**: 确保执行了建表SQL
2. **端口冲突**: 如3000/8080端口被占用，请修改配置
3. **首次登录**: 使用默认账号 admin/admin
4. **及时修改密码**: 登录后请在"系统设置"中修改密码

## 常见问题

**Q: 数据库连接失败？**
A: 检查MySQL是否启动，.env配置是否正确

**Q: 登录失败？**
A: 确认已执行建表SQL，默认账号为admin/admin

**Q: 图片上传失败？**
A: 检查uploads目录权限，确保可写入

**Q: 页面空白？**
A: 检查后端是否启动，浏览器控制台是否有错误
