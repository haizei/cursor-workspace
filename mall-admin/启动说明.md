# 商城管理后台系统 - 启动说明

## 项目说明

这是一个功能完整的商城管理后台系统，采用全栈一体化架构开发：

- **后端**：Node.js + Express + MySQL + JWT
- **前端**：Vue.js 2.x + Element UI + Vuex + Vue Router + ECharts
- **特点**：前后端在同一项目中，支持独立开发和一键部署

## 功能列表

✅ **左侧树型菜单栏**：直观的树型结构导航
✅ **数据统计仪表盘**：核心指标展示和图表分析
✅ **商品管理**：商品列表、新增、编辑、上下架、推荐设置
✅ **分类管理**：分类列表、新增、编辑、删除
✅ **轮播图管理**：轮播图列表、新增、编辑、上下架
✅ **订单管理**：订单列表、详情、发货、关闭订单
✅ **用户管理**：用户列表、详情、启用/禁用
✅ **权限管理**：管理员登录、退出、修改密码
✅ **图片上传**：支持商品图、分类图、轮播图上传

## 启动步骤

### 1. 安装依赖

```bash
# 进入项目目录
cd mall-admin

# 安装后端依赖
npm install

# 安装前端依赖
cd frontend
npm install
cd ..
```

或者使用快捷命令：
```bash
npm run install:all
```

### 2. 配置数据库

#### 2.1 创建数据库
```bash
# 登录MySQL
mysql -u root -p

# 创建数据库
CREATE DATABASE IF NOT EXISTS `mall` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

#### 2.2 导入数据表
```bash
# 执行SQL文件（使用项目需求目录中的数据库建表语句.sql）
mysql -u root -p mall < ../商城小程序项目需求/数据库建表语句.sql
```

### 3. 配置环境变量

项目根目录已有 `.env` 文件，请修改其中的数据库配置：

```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的数据库密码
DB_NAME=mall
```

### 4. 启动项目

#### 方式一：开发模式（前后端分离）

**终端1 - 启动后端服务器：**
```bash
npm run dev
```
后端服务运行在：http://localhost:3000

**终端2 - 启动前端开发服务器：**
```bash
npm run frontend:dev
```
前端服务运行在：http://localhost:8080

访问：http://localhost:8080

#### 方式二：生产模式（前后端一体）

```bash
# 1. 构建前端
npm run frontend:build

# 2. 启动服务器
npm start
```

访问：http://localhost:3000

## API接口说明

所有API接口以 `/api` 开头，管理后台接口以 `/api/admin` 开头。

### 认证接口
- `POST /api/admin/auth/login` - 管理员登录
- `POST /api/admin/auth/logout` - 管理员退出
- `POST /api/admin/auth/changepwd` - 修改密码

### 商品接口
- `GET /api/admin/goods/list` - 获取商品列表
- `GET /api/admin/goods/detail/:id` - 获取商品详情
- `POST /api/admin/goods/save` - 保存商品
- `DELETE /api/admin/goods/delete/:id` - 删除商品
- `POST /api/admin/goods/setstatus` - 设置商品状态

### 分类接口
- `GET /api/admin/category/list` - 获取分类列表
- `GET /api/admin/category/all` - 获取所有分类
- `POST /api/admin/category/save` - 保存分类
- `DELETE /api/admin/category/delete/:id` - 删除分类

### 轮播图接口
- `GET /api/admin/banner/list` - 获取轮播图列表
- `POST /api/admin/banner/save` - 保存轮播图
- `DELETE /api/admin/banner/delete/:id` - 删除轮播图
- `POST /api/admin/banner/setstatus` - 设置轮播图状态

### 订单接口
- `GET /api/admin/order/list` - 获取订单列表
- `GET /api/admin/order/detail/:id` - 获取订单详情
- `POST /api/admin/order/deliver` - 订单发货
- `POST /api/admin/order/close` - 关闭订单

### 用户接口
- `GET /api/admin/user/list` - 获取用户列表
- `GET /api/admin/user/detail/:id` - 获取用户详情
- `POST /api/admin/user/setstatus` - 设置用户状态

### 统计接口
- `GET /api/admin/stat/dashboard` - 获取仪表盘数据

### 上传接口
- `POST /api/upload/image` - 上传图片

## 常见问题

### 1. 数据库连接失败
- 检查MySQL服务是否启动
- 检查 `.env` 文件中的数据库配置是否正确
- 确认数据库用户权限

### 2. 登录失败
- 确认数据库中是否有默认管理员账号
- 检查密码是否正确（默认：admin/admin）
- 查看后端控制台日志

### 3. 图片上传失败
- 确认 `uploads` 目录存在且有写入权限
- 检查文件大小是否超过限制（5MB）
- 检查文件格式是否支持

### 4. 前端页面空白
- 检查后端API是否正常启动
- 查看浏览器控制台是否有错误
- 确认路由配置是否正确
