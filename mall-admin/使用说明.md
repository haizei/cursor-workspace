# 商城管理后台系统 - 使用说明

## 项目概述

这是一个完整的商城小程序管理后台系统，采用全栈一体化架构开发：
- **后端**: Node.js + Express + MySQL
- **前端**: Vue.js 2.x + Element UI + ECharts
- **特色**: 左侧树形菜单、完整的CRUD功能、数据统计可视化

## 安装部署

### 1. 环境要求
- Node.js >= 14.0
- MySQL >= 5.7
- npm 或 yarn

### 2. 数据库准备

```bash
# 1. 创建数据库
mysql -u root -p

# 2. 执行建表语句
# 使用项目需求文档中的 数据库建表语句.sql
source /path/to/数据库建表语句.sql
```

### 3. 安装依赖

```bash
# 进入项目目录
cd mall-admin

# 安装后端依赖
npm install

# 安装前端依赖
cd frontend
npm install
cd ..
```

### 4. 配置环境变量

修改 `.env` 文件，配置数据库连接：

```env
# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=mall

# 其他配置保持默认即可
```

## 运行项目

### 开发模式

**方式一：分别启动前后端**

```bash
# 终端1：启动后端服务器
npm run dev
# 后端运行在 http://localhost:3000

# 终端2：启动前端开发服务器
npm run frontend:dev
# 前端运行在 http://localhost:8080
```

访问: http://localhost:8080

**方式二：只启动后端（需先构建前端）**

```bash
# 先构建前端
npm run frontend:build

# 启动后端服务器
npm start

# 访问 http://localhost:3000
```

### 生产模式

```bash
# 1. 构建前端
npm run frontend:build

# 2. 启动服务器
npm start

# 3. 访问
# 默认地址: http://localhost:3000
```

## API接口说明

所有API接口均以 `/admin` 为前缀，需要携带 Authorization Token。

### 认证相关
- POST `/admin/auth/login` - 管理员登录
- GET `/admin/auth/info` - 获取管理员信息
- POST `/admin/auth/logout` - 退出登录
- POST `/admin/auth/changepwd` - 修改密码

### 商品管理
- GET `/admin/goods/list` - 获取商品列表
- GET `/admin/goods/detail/:id` - 获取商品详情
- POST `/admin/goods/save` - 保存商品
- DELETE `/admin/goods/delete/:id` - 删除商品
- POST `/admin/goods/setstatus` - 设置商品状态

### 分类管理
- GET `/admin/category/list` - 获取分类列表
- POST `/admin/category/save` - 保存分类
- DELETE `/admin/category/delete/:id` - 删除分类

### 轮播图管理
- GET `/admin/banner/list` - 获取轮播图列表
- POST `/admin/banner/save` - 保存轮播图
- DELETE `/admin/banner/delete/:id` - 删除轮播图

### 订单管理
- GET `/admin/order/list` - 获取订单列表
- GET `/admin/order/detail/:id` - 获取订单详情
- POST `/admin/order/deliver` - 订单发货
- POST `/admin/order/close` - 关闭订单

### 用户管理
- GET `/admin/user/list` - 获取用户列表
- GET `/admin/user/detail/:id` - 获取用户详情
- POST `/admin/user/setstatus` - 设置用户状态

### 统计数据
- GET `/admin/stat/dashboard` - 获取仪表盘数据

### 文件上传
- POST `/admin/upload/image` - 上传单张图片
- POST `/admin/upload/images` - 上传多张图片

## 常见问题

### 1. 数据库连接失败
- 检查MySQL是否启动
- 确认数据库配置信息是否正确
- 确认数据库已创建且执行了建表语句

### 2. 登录提示用户名或密码错误
- 确认已执行数据库建表语句
- 检查admin表中是否有默认管理员账号
- 默认账号密码都是 `admin`

### 3. 图片上传失败
- 检查uploads目录是否有写入权限
- 确认图片格式和大小符合要求
- 查看后端日志排查错误

### 4. 前端页面空白
- 检查是否已安装前端依赖
- 确认后端服务是否启动
- 查看浏览器控制台错误信息

### 5. 端口被占用
- 修改 `.env` 文件中的 PORT 配置
- 或修改 `frontend/vue.config.js` 中的前端端口
