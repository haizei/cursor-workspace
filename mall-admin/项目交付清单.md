## 🛠 技术栈

### 后端
- **框架**: Node.js + Express
- **数据库**: MySQL
- **认证**: JWT
- **加密**: bcrypt
- **上传**: Multer
- **日志**: 自定义Logger

### 前端
- **框架**: Vue.js 2.7
- **UI库**: Element UI 2.15
- **图表**: ECharts 5.4
- **路由**: Vue Router 3.6
- **状态**: Vuex 3.6
- **HTTP**: Axios 1.5
