【重要文件说明】

1. server.js - 后端服务器入口
   主要功能：
   - 启动Express服务器
   - 静态文件服务（前端dist目录）
   - 注册API路由
   - 错误处理

2. frontend/src/main.js - 前端入口
   主要功能：
   - 创建Vue实例
   - 引入Element UI
   - 注册路由
   - 注册状态管理

3. frontend/src/router/index.js - 路由配置
   主要路由：
   - /login - 登录页
   - /dashboard - 首页（数据统计）
   - /goods/list - 商品列表
   - /goods/edit - 商品编辑
   - /order/list - 订单列表
   - /user/list - 用户列表
   - ... 其他路由

4. frontend/src/api/ - API请求封装
   功能：
   - 统一请求方法
   - 自动添加Token
   - 统一错误处理
   - 未登录时跳转登录页

5. frontend/src/store/ - 状态管理
   主要状态：
   - 用户信息（登录状态）
   - 权限信息
   - 其他全局状态

6. backend/routes/admin/ - 管理后台API路由
   所有路由以 /admin 开头
   需要管理员认证


【目录命名规范】

1. 前端文件：使用驼峰命名法（PascalCase）
   - 组件：GoodsList.vue、OrderDetail.vue
   - 页面：Login.vue、Dashboard.vue

2. 后端文件：使用驼峰命名法（camelCase）
   - 控制器：goodsController.js
   - 路由：goods.js

3. 目录命名：使用小写字母
   - 例如：components、views、controllers


【开发流程】

1. 前端开发
   - 在 frontend/ 目录下开发
   - 使用 npm run serve 启动开发服务器
   - 使用 npm run build 打包前端代码

2. 后端开发
   - 在 backend/ 目录下开发
   - 开发API接口
   - 测试接口功能

3. 部署
   - 先打包前端：npm run build
   - 打包后的文件在 frontend/dist/
   - 将 dist/ 目录内容复制到 public/
   - 启动后端服务：node server.js
   - 访问 http://localhost:端口号


【前端页面结构示例】

1. 商品列表页（GoodsList.vue）
   - 顶部：搜索栏、筛选条件
   - 中间：商品表格（使用Element UI Table组件）
   - 底部：分页组件
   - 操作：编辑、删除、上下架按钮

2. 商品编辑页（GoodsEdit.vue）
   - 表单：商品名称、价格、库存等
   - 图片上传：主图、轮播图
   - 操作：保存、取消按钮

3. 订单列表页（OrderList.vue）
   - 顶部：搜索栏、订单状态筛选
   - 中间：订单表格
   - 底部：分页组件
   - 操作：查看详情、发货按钮

4. 数据统计页（Dashboard.vue）
   - 顶部：核心指标卡片（订单数、销售额等）
   - 中间：图表（使用ECharts）
   - 底部：数据表格


【技术栈说明】

1. 前端
   - Vue.js：前端框架
   - Vue Router：路由管理
   - Vuex：状态管理（可选）
   - Element UI：UI组件库
   - Axios：HTTP请求
   - ECharts：数据可视化

2. 后端
   - Node.js + Express：服务端框架
   - MySQL/MongoDB：数据库
   - JWT：管理员认证
   - Multer：文件上传处理

3. 部署
   - PM2：进程管理
   - Nginx：反向代理（可选）
