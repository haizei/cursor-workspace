【重要文件说明】

1. server.js - 服务器入口
   主要功能：
   - 引入Express框架
   - 加载配置和中间件
   - 注册路由
   - 启动服务器监听端口

2. config/database.js - 数据库配置
   示例代码：
   - MySQL连接配置
   - 连接池配置
   - 数据库连接测试

3. middleware/auth.js - 认证中间件
   功能：
   - 验证请求头中的Token
   - 解析用户信息
   - 将用户信息添加到请求对象

4. utils/response.js - 统一响应格式
   返回格式：
   {
     code: 200,
     message: "成功",
     data: {}
   }

5. routes/ - 路由文件
   职责：
   - 定义API路径
   - 调用对应的控制器
   - 添加中间件（认证、验证等）

6. controllers/ - 控制器
   职责：
   - 处理业务逻辑
   - 调用模型层操作数据库
   - 返回数据给路由

7. models/ - 模型层
   职责：
   - 定义数据表结构
   - 封装数据库操作方法
   - 数据验证和处理


【目录命名规范】

1. 文件命名：使用驼峰命名法（camelCase）
   - 例如：goodsController.js、orderController.js

2. 目录命名：使用小写字母
   - 例如：controllers、middleware、utils

3. 类名命名：使用大驼峰命名法（PascalCase）
   - 例如：Banner、Goods、Order


【开发建议】

1. 代码分层
   - 路由层：只负责路由定义和参数验证
   - 控制器层：处理业务逻辑
   - 模型层：数据库操作
   - 工具层：通用工具函数

2. 错误处理
   - 统一使用错误处理中间件
   - 记录错误日志
   - 返回友好的错误信息

3. 安全性
   - 所有用户输入都要验证
   - 使用参数化查询防止SQL注入
   - 敏感信息加密存储
   - 接口添加限流保护

4. 代码规范
   - 使用ESLint规范代码
   - 统一代码风格
   - 添加必要注释
   - 遵循最佳实践

5. 数据库操作
   - 使用连接池管理数据库连接
   - 所有查询使用参数化查询
   - 事务处理（重要操作）
   - 数据库索引优化
