========================================
Homebrew 国内镜像安装方法（解决连接失败问题）
========================================

【问题说明】
----------------------------------------
如果遇到以下错误：
Failed to connect to raw.githubusercontent.com port 443 after 3 ms: Couldn't connect to server

这是因为无法访问 GitHub，需要使用国内镜像源。


【方法一：使用国内镜像源安装（推荐）】
----------------------------------------

步骤1：使用清华大学镜像源安装
--------------------------------
在终端中执行以下命令：

export HOMEBREW_BREW_GIT_REMOTE="https://mirrors.tuna.tsinghua.edu.cn/git/homebrew/brew.git"
export HOMEBREW_CORE_GIT_REMOTE="https://mirrors.tuna.tsinghua.edu.cn/git/homebrew/homebrew-core.git"
/bin/bash -c "$(curl -fsSL https://mirrors.tuna.tsinghua.edu.cn/git/homebrew/install/HEAD/install.sh)"

如果上面的镜像也不行，可以尝试其他镜像：

# 使用腾讯云镜像
export HOMEBREW_BREW_GIT_REMOTE="https://mirrors.cloud.tencent.com/homebrew/brew.git"
export HOMEBREW_CORE_GIT_REMOTE="https://mirrors.cloud.tencent.com/homebrew/homebrew-core.git"
/bin/bash -c "$(curl -fsSL https://mirrors.cloud.tencent.com/homebrew/install/HEAD/install.sh)"

# 或使用阿里云镜像（如果支持）
export HOMEBREW_BREW_GIT_REMOTE="https://mirrors.aliyun.com/homebrew/brew.git"
export HOMEBREW_CORE_GIT_REMOTE="https://mirrors.aliyun.com/homebrew/homebrew-core.git"
/bin/bash -c "$(curl -fsSL https://mirrors.aliyun.com/homebrew/install/HEAD/install.sh)"


步骤2：配置环境变量
--------------------------------
安装完成后，根据你的 Mac 类型配置：

【Apple Silicon Mac (M1/M2/M3)】
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

【Intel Mac】
echo 'eval "$(/usr/local/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/usr/local/bin/brew shellenv)"


步骤3：配置镜像源加速（安装后）
--------------------------------
安装完成后，继续使用国内镜像源：

# Apple Silicon Mac
cd "$(brew --repo)"
git remote set-url origin https://mirrors.tuna.tsinghua.edu.cn/git/homebrew/brew.git

cd "$(brew --repo)/Library/Taps/homebrew/homebrew-core"
git remote set-url origin https://mirrors.tuna.tsinghua.edu.cn/git/homebrew/homebrew-core.git

# Intel Mac
cd "$(brew --repo)"
git remote set-url origin https://mirrors.tuna.tsinghua.edu.cn/git/homebrew/brew.git

cd "$(brew --repo)/Library/Taps/homebrew/homebrew-core"
git remote set-url origin https://mirrors.tuna.tsinghua.edu.cn/git/homebrew/homebrew-core.git

# 设置二进制包镜像（bottles）
echo 'export HOMEBREW_BOTTLE_DOMAIN=https://mirrors.tuna.tsinghua.edu.cn/homebrew-bottles' >> ~/.zprofile
source ~/.zprofile

# 更新
brew update


【方法二：手动下载安装脚本】
----------------------------------------

如果镜像源也不行，可以手动下载安装脚本：

步骤1：下载安装脚本
--------------------------------
1. 访问国内镜像站，手动下载安装脚本
2. 或使用浏览器访问以下链接下载 install.sh：
   https://mirrors.tuna.tsinghua.edu.cn/git/homebrew/install/HEAD/install.sh
   或
   https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh

步骤2：执行安装脚本
--------------------------------
# 将下载的脚本保存为 install.sh，然后执行
chmod +x install.sh
./install.sh


【方法三：使用 gitee 镜像安装（备选）】
----------------------------------------

执行以下命令：

/bin/bash -c "$(curl -fsSL https://gitee.com/ineo6/homebrew-install/raw/master/install.sh)"

这个方法会自动配置国内镜像源。


【方法四：使用代理（如果你有VPN）】
----------------------------------------

如果你有可用的代理/VPN：

步骤1：设置代理环境变量
--------------------------------
# 假设你的代理端口是 7890（根据实际情况修改）
export http_proxy=http://127.0.0.1:7890
export https_proxy=http://127.0.0.1:7890

步骤2：执行原始安装命令
--------------------------------
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"


【方法五：使用一键安装脚本（最简单）】
----------------------------------------

国内开发者提供的 Homebrew 一键安装脚本：

执行：
/bin/bash -c "$(curl -fsSL https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh)"

这个脚本会：
- 自动选择国内镜像源
- 自动配置环境变量
- 自动测试安装是否成功


【验证安装】
----------------------------------------

无论使用哪种方法，安装完成后验证：

# 检查 Homebrew 版本
brew --version

# 测试安装一个软件（如 wget）
brew install wget


【如果仍然无法连接】
----------------------------------------

检查网络连接：
--------------------------------
# 测试网络连接
ping mirrors.tuna.tsinghua.edu.cn

# 如果 ping 不通，检查 DNS 设置
# 可以尝试更换 DNS 为：
# 114.114.114.114（114 DNS）
# 或 8.8.8.8（Google DNS）


检查防火墙：
--------------------------------
确保防火墙没有阻止终端访问网络


使用手机热点：
--------------------------------
如果宽带无法连接，可以尝试使用手机热点作为临时网络


【安装完成后的配置】
----------------------------------------

无论使用哪种方法安装，建议配置镜像源加速：

# 配置 brew 和 core 镜像
brew tap --custom-remote --force-auto-update homebrew/core https://mirrors.tuna.tsinghua.edu.cn/git/homebrew/homebrew-core.git

# 配置 bottles 镜像
echo 'export HOMEBREW_BOTTLE_DOMAIN=https://mirrors.tuna.tsinghua.edu.cn/homebrew-bottles' >> ~/.zprofile
source ~/.zprofile

# 更新
brew update


【推荐方案总结】
----------------------------------------

对于国内用户，推荐按以下顺序尝试：

1. 首选：使用 gitee 一键安装脚本
   /bin/bash -c "$(curl -fsSL https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh)

2. 备选：使用清华大学镜像源
   （见方法一的步骤1）

3. 如果有代理：使用方法四

4. 最后选择：手动下载安装脚本


【下一步】
----------------------------------------

安装成功后，继续安装项目所需软件：

brew install node      # Node.js
brew install mysql     # MySQL
brew install git       # Git


【常见问题】
----------------------------------------

Q: 安装过程中提示需要 Xcode Command Line Tools？
A: 执行：xcode-select --install

Q: 安装后 brew 命令找不到？
A: 检查并配置环境变量（见方法一的步骤2）

Q: brew update 很慢？
A: 确保已配置国内镜像源（见方法一的步骤3）
